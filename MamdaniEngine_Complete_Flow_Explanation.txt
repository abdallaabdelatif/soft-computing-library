# Complete Flow Explanation of MamdaniEngine with Examples

## **Overview**

The `MamdaniEngine` implements **Mamdani fuzzy inference**, which is a method for processing fuzzy rules to produce fuzzy outputs. It evaluates each rule, computes firing strengths, and generates discretized membership functions (curves) that represent the fuzzy output of each rule.

---

## **Method Signature**

```java
public Map<String, double[]> infer(
    Map<String, Map<String, Double>> fuzzifiedInputs,
    RuleBase ruleBase,
    LinguisticVariable outputVar)
```

### **Inputs:**

1. **`fuzzifiedInputs`**: `Map<String, Map<String, Double>>`
   - Outer key: Input variable name (e.g., "TrafficDensity")
   - Inner map: Fuzzy set name → Membership degree
   - Example:
     ```java
     {
       "TrafficDensity": {"Low": 0.0, "Medium": 0.3, "High": 0.7},
       "WaitingTime": {"Short": 0.0, "Medium": 0.2, "Long": 0.9}
     }
     ```

2. **`ruleBase`**: `RuleBase`
   - Collection of fuzzy rules to evaluate
   - Each rule has an antecedent (IF part) and consequent (THEN part)

3. **`outputVar`**: `LinguisticVariable`
   - The output linguistic variable (e.g., GreenDuration)
   - Contains fuzzy sets for the output domain

### **Output:**

- **`Map<String, double[]>`**
  - Key: Rule identifier (e.g., "rule_0_Long")
  - Value: `double[121]` array representing a discretized membership function
  - Each array contains 121 sampled points over the output domain


#### **5a. Skip Null or Disabled Rules (Lines 41-43)**

```java
if (rule == null || !rule.isEnabled()) {
    continue;
}
```

- Only processes enabled rules
- Allows rules to be temporarily disabled without deletion

#### **5b. Extract Antecedent and Consequent (Lines 45-50)**

```java
RuleAntecedent antecedent = rule.getAntecedent();
```

- Gets the IF part (antecedent) and THEN part (consequent) of the rule
- Skips rules with missing components

#### **5c. Compute Rule Evaluation (Firing Strength) (Line 52)**

```java
double evaluation = ruleEvaluation(fuzzifiedInputs, antecedent);
```

- Calls `ruleEvaluation()` method to compute firing strength
- This method uses **minimum t-norm** to combine all antecedent conditions
- Returns a value in [0.0, 1.0] representing how well the rule matches the inputs

**How `ruleEvaluation()` works:**
- Extracts conditions from antecedent (e.g., `{"TrafficDensity": "High", "WaitingTime": "Long"}`)
- For each condition, looks up membership degree in `fuzzifiedInputs`
- Applies minimum operation: `evaluation = min(evaluation, mu)`
- Returns the minimum of all condition memberships

#### **5d. Skip Rules with Zero Firing Strength (Lines 54-56)**

```java
if (evaluation <= 0.0) {
    continue;
}
```

- If the rule doesn't fire (evaluation = 0), skip it
- No need to process rules that don't contribute

#### **5e. Apply Rule Weight (Line 58)**

```java
evaluation *= rule.getWeight();
```

- Multiplies firing strength by rule weight
- Rule weight is typically in [0.0, 1.0] (default = 1.0)
- Allows rules to be weighted differently (e.g., more important rules have higher weight)
- Example: If `evaluation = 0.7` and `weight = 0.8`, then `evaluation = 0.56`

#### **5f. Skip If Weighted Strength is Zero (Lines 60-62)**

```java
if (evaluation <= 0.0) {
    continue;
}
```

- Final check after applying weight
- Ensures only active rules proceed

#### **5g. Get Output Fuzzy Set (Lines 64-67)**

```java
FuzzySet outputSet = outputVar.getFuzzySet(consequent.getOutputFuzzySet());
if (outputSet == null) {
    continue;
}
```

- Retrieves the fuzzy set specified in the rule's consequent
- Example: If consequent says "Long", gets the "Long" fuzzy set from GreenDuration variable
- Skips if the fuzzy set doesn't exist

#### **5h. Get Membership Function (Line 69)**

```java
MembershipFunction mf = outputSet.getMembershipFunction();
```

- Extracts the membership function (Triangular, Trapezoidal, or Gaussian)
- This defines the shape of the output fuzzy set

#### **5i. Create the Output Curve (Mamdani Implication) (Lines 72-77)**

```java
double[] curve = new double[NUM_SAMPLES];
for (int i = 0; i < NUM_SAMPLES; i++) {
    double x = rangeStart + i * step;        // x value in output domain
    double baseMu = mf.compute(x);          // Original membership at x
    curve[i] = Math.min(evaluation, baseMu); // Clipped membership
}
```

**This is the core of Mamdani inference:**

- **Line 74**: Calculates the x-coordinate in the output domain
  - Example: For `i = 0`: `x = 0 + 0 × 1.0 = 0`
  - For `i = 60`: `x = 0 + 60 × 1.0 = 60`
  - For `i = 120`: `x = 0 + 120 × 1.0 = 120`

- **Line 75**: Computes the original membership of the output fuzzy set at point x
  - Example: For "Long" fuzzy set at `x = 80`, `baseMu` might be `0.8`

- **Line 76**: Applies **Mamdani implication** (clipping operation)
  - Formula: `μ_output(x) = min(α, μ_consequent(x))`
  - Where `α` = `evaluation` (firing strength)
  - This clips the membership function at the firing strength level

**Visual Representation:**

**Before Clipping (Base Membership Function):**
```

   1.0 |        /\
       |       /  \
   0.7 |      /    \
       |     /      \
   0.0 |____/        \____
       0    40    80    120  (GreenDuration in seconds)
```

**After Clipping at `evaluation = 0.7`:**
```
Membership
   1.0 |
       |
   0.7 |═══════════════════  ← Clipped at 0.7
       |     /      \
   0.0 |____/        \____
       0    40    80    120  (GreenDuration in seconds)
```

```java

```

- Creates a unique key for the rule (e.g., "rule_0_Long")

## **Complete Example: Traffic Light Problem**

### **Problem Setup:**

**Input Variables:**
- **TrafficDensity**: Domain [0, 100]
  - Fuzzy sets: Low (Triangular: 0, 0, 30), Medium (Trapezoidal: 20, 35, 65, 80), High (Triangular: 60, 100, 100)
- **WaitingTime**: Domain [0, 180]
  - Fuzzy sets: Short (Triangular: 0, 0, 60), Medium (Trapezoidal: 50, 70, 110, 130), Long (Triangular: 110, 180, 180)

**Output Variable:**
- **GreenDuration**: Domain [0, 120]
  - Fuzzy sets: Short (Triangular: 0, 0, 40), Medium (Trapezoidal: 30, 45, 65, 80), Long (Triangular: 70, 120, 120)

**Rules:**
1. `IF TrafficDensity IS High AND WaitingTime IS Long THEN GreenDuration IS Long`
2. `IF TrafficDensity IS Medium AND WaitingTime IS Medium THEN GreenDuration IS Medium`
3. `IF TrafficDensity IS Low AND WaitingTime IS Short THEN GreenDuration IS Short`

## **What Happens Next (After MamdaniEngine)**

The output from MamdaniEngine goes through:

1. **Aggregation** (`Aggregator.aggregateMamdani()`):
   - Combines all rule curves using **max operation** (union)
   - Pointwise: `aggregated[i] = max(curve1[i], curve2[i], ...)`
   - Result: Single aggregated curve `double[121]`

2. **Defuzzification** (`Defuzzifier.defuzzify()`):
   - Converts aggregated fuzzy set to crisp value
   - Methods: Centroid (center of mass) or Mean of Maximum
   - Result: Final crisp output (e.g., GreenDuration = 65.3 seconds)

## **Key Concepts**

### **1. Mamdani Implication**
- Formula: `μ_output(x) = min(α, μ_consequent(x))`
- Clips the output membership function at the firing strength level
- Preserves the shape of the output fuzzy set but limits its height

### **2. Discretization**
- Output domain is sampled at 121 points
- Provides sufficient resolution for accurate defuzzification
- Step size = `(rangeEnd - rangeStart) / 120`

### **3. Rule Firing Strength**
- Determined by the **weakest** antecedent condition (minimum t-norm)
- Represents how well the rule matches the current inputs
- Scales the rule's contribution to the final output

### **4. Curve Representation**
- Each rule produces a discretized membership function
- Stored as `double[121]` array
- Represents the fuzzy output contribution of that rule

---

## **Mathematical Summary**

For each rule \(r\):

1. **Firing Strength:**
   \[
   \alpha_r = \min_{i=1}^{n} \mu_{A_i}(x_i) \times w_r
   \]
   Where:
   - \(n\) = number of antecedent conditions
   - \(\mu_{A_i}(x_i)\) = membership degree of condition \(i\)
   - \(w_r\) = rule weight

2. **Mamdani Implication:**
   \[
   \mu_r(x) = \min(\alpha_r, \mu_{B_r}(x))
   \]
   Where:
   - \(\mu_{B_r}(x)\) = membership function of consequent fuzzy set
   - \(\mu_r(x)\) = clipped output membership function

3. **Output:**
   - Discretized curve: \(\{\mu_r(x_0), \mu_r(x_1), ..., \mu_r(x_{120})\}\)
   - Where \(x_i = \text{rangeStart} + i \times \text{step}\)

## **Code Reference**

```java
public class MamdaniEngine implements InferenceEngine {
    private static final int NUM_SAMPLES = 121;

    @Override
    public Map<String, double[]> infer(
            Map<String, Map<String, Double>> fuzzifiedInputs,
            RuleBase ruleBase,
            LinguisticVariable outputVar) {
        
        Map<String, double[]> ruleOutputs = new LinkedHashMap<>();
        
        if (ruleBase == null || ruleBase.getRules().isEmpty()) {
            return ruleOutputs;
        }
        
        double rangeStart = outputVar.getDomainMin();
        double rangeEnd = outputVar.getDomainMax();
        
        if (rangeEnd <= rangeStart) {
            throw new IllegalArgumentException("Output variable domain must have rangeEnd > rangeStart.");
        }
        
        double step = (rangeEnd - rangeStart) / (NUM_SAMPLES - 1);
        
        int ruleIndex = 0;
        for (FuzzyRule rule : ruleBase.getRules()) {
            if (rule == null || !rule.isEnabled()) {
                continue;
            }
            
            RuleAntecedent antecedent = rule.getAntecedent();
            RuleConsequent consequent = rule.getConsequent();
            
            if (antecedent == null || consequent == null) {
                continue;
            }
            
            double evaluation = ruleEvaluation(fuzzifiedInputs, antecedent);
            
            if (evaluation <= 0.0) {
                continue;
            }
            
            evaluation *= rule.getWeight();
            
            if (evaluation <= 0.0) {
                continue;
            }
            
            FuzzySet outputSet = outputVar.getFuzzySet(consequent.getOutputFuzzySet());
            if (outputSet == null) {
                continue;
            }
            
            MembershipFunction mf = outputSet.getMembershipFunction();
            
            double[] curve = new double[NUM_SAMPLES];
            for (int i = 0; i < NUM_SAMPLES; i++) {
                double x = rangeStart + i * step;
                double baseMu = mf.compute(x);
                curve[i] = Math.min(evaluation, baseMu);
            }
            
            String key = "rule_" + ruleIndex + "_" + consequent.getOutputFuzzySet();
            ruleOutputs.put(key, curve);
            ruleIndex++;
        }
        
        return ruleOutputs;
    }
    
    private double ruleEvaluation(
            Map<String, Map<String, Double>> fuzzifiedInputs,
            RuleAntecedent antecedent) {
        
        Map<String, String> conditions = antecedent.getConditions();
        if (conditions == null || conditions.isEmpty()) {
            return 0.0;
        }
        
        double evaluation = 1.0;
        
        for (Map.Entry<String, String> entry : conditions.entrySet()) {
            String varName = entry.getKey();
            String setName = entry.getValue();
            
            Map<String, Double> membershipsForVar = fuzzifiedInputs.get(varName);
            if (membershipsForVar == null) {
                return 0.0;
            }
            
            Double mu = membershipsForVar.get(setName);
            if (mu == null) {
                return 0.0;
            }
            
            evaluation = Math.min(evaluation, mu);
            
            if (evaluation <= 0.0) {
                return 0.0;
            }
        }
        
        return evaluation;
    }
}
```
